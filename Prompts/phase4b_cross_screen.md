# Фаза 4б — экран скрещивания

Прочитай genolab_tz.md (раздел 3.2), LOG.md и docs/api.md.
Ты работаешь ТОЛЬКО через экспорты из docs/api.md. Если нужной функции
в api.md нет — остановись и спроси, а не придумывай вызов.

Реализуй:
1. Экран скрещивания: два слота родителей (выбор из вольера),
   кнопка «Случайно», анимация скрещивания 1–2 с (CSS-анимация),
   лента результатов с рендером потомков (creature.js).
2. Результаты добавляются в вольер через store.js с учётом лимита
   12 слотов (при переполнении — диалог выбора, кого оставить).

Ограничения: не менять математику breeder.js, genome.js, store.js
и save.js; анимации только через CSS. Не трогай файлы вне экрана
скрещивания и ui/components.

Проверка себя через chrome-devtools (E2E-сценарий):
1. Открой игру, добавь в вольер тестовых родителей (через evaluate
   или интерфейс).
2. Пройди: выбор родителей → «Случайно» → скрещивание → лента потомков.
3. Прочитай консоль после каждого шага — ошибок быть не должно.
4. Скриншот финального состояния ленты приложи к LOG.md.
5. Проверь: потомки реально записаны в store и сохранились
   (localStorage, evaluate).

Критерий готовности: цикл скрещивания работает без ошибок консоли,
потомки сохраняются между перезагрузками.

Соблюдай APPEND_SYSTEM.md, AGENTS.md, RULES.md, SECURITY.md.
После выполнения: запиши запись в LOG.md по формату LOGGING.md
(что сделал / что проверил запуском / что НЕ проверял / файлы вне задания: не трогал),
сделай скриншот страницы через chrome-devtools и приложи путь в записи.
Не объясняй код в ответе — только файлы и запись в журнал.
