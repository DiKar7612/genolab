# Фаза 1 — геном и скрещивание (ГЕЙТ)

Прочитай genolab_tz.md (разделы 3.1, 5, 7) и LOG.md (итоги фазы 0).
Реализуй ядро генетики:

1. js/data/species.json — один вид, 4 признака (окрас, узор, размер,
   форма ушей), у каждого пара аллелей, полное доминирование.
   Формат: { geneId: { alleles: [{id, dominant}], phenotypes: {...} } }.
2. js/core/genome.js — класс генома; функция genomeToPhenotype(genome)
   по правилам из species.json; валидация генома.
3. js/core/breeder.js — cross(parentA, parentB) возвращает 1–4 потомков:
   для каждого гена по одному аллелю от каждого родителя равновероятно.
   Отдельная чистая функция pennettGrid(parentA, parentB) возвращает
   решётку 2x2 или 4x4 с долями генотипов/фенотипов.
4. js/core/rng.js — обёртка над Math.random с возможностью задать seed
   (mulberry32), чтобы тесты были воспроизводимыми.
5. tests/breeder.test.html и tests/genome.test.html — страница,
   прогоняющая 10 000 скрещиваний Aa×Aa (ожидание 3:1 ±5%),
   Aa×aa (1:1 ±5%), AaBb×AaBb (9:3:3:1 ±3%) и выводящая результаты
   в DOM, а не только в консоль.

Ограничения: функции breeder.js — чистые, без обращения к DOM.
Не трогай файлы вне перечисленных (кроме записи в LOG.md).

Проверка себя через chrome-devtools (обязательная, это гейт):
1. Открой file:///F:/genolab/tests/breeder.test.html.
2. Прочитай содержимое блока с результатами ИЗ DOM — процитируй его
   в LOG.md дословно: числа расщеплений и отклонения по каждому тесту.
3. Если хоть один тест FAIL — исправь код и перезапусти прогон.
   Отчитываться с проваленными тестами запрещено.

Гейт: фаза закрыта только при PASS по всем трём распределениям.
Подтверждение гейта — дословный вывод тестов в LOG.md, не пересказ.
