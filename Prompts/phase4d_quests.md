# Фаза 4г — заказы и квесты

Прочитай genolab_tz.md (разделы 3.2–3.3), LOG.md и docs/api.md.
Работай только через экспорты из docs/api.md; нет нужной функции —
остановись и спроси.

Реализуй:
1. js/data/quests.json — 5 обучающих квестов и 5 заказов. Каждый квест
   открывает одно понятие в порядке: полное доминирование →
   гетерозигота → рецессивный признак → фиксация признака →
   предсказание расщепления. Тексты — по смыслу ТЗ, без нового
   контента сверх ТЗ.
2. js/quests/questEngine.js — проверка условий квестов (цель вида
   «получи N потомков с фенотипом X» / «выполни заказ»), выдача наград,
   линейная разблокировка.
3. Экран заказов: список активных заказов с фильтром по признакам,
   кнопка «Выполнить» активна, если в вольере есть подходящий потомок.
4. Прогресс квестов сохраняется через store/save.

Ограничения: не менять breeder.js, genome.js, economy.js.

Проверка себя через chrome-devtools:
1. Пройди все 5 квестов последовательно через интерфейс (скрещивай
   нужных родителей, выполняя условия). Фиксируй в LOG.md после каждого
   квеста: номер, выполнено/нет, награда начислена.
2. Консоль чистая на каждом шаге.
3. Перезагрузка: прогресс квестов не сбросился.
4. Если квест невозможно пройти за разумное число скрещиваний
   (условие недостижимо при данных родителях) — исправь квест-конфиг,
   не код логики.

Критерий готовности: все 5 квестов проходимы последовательно,
прогресс сохраняется, консоль чистая. Финальную сверку играбельности
выполняет пользователь.

Соблюдай APPEND_SYSTEM.md, AGENTS.md, RULES.md, SECURITY.md.
После выполнения: запиши запись в LOG.md по формату LOGGING.md
(что сделал / что проверил запуском / что НЕ проверял / файлы вне задания: не трогал),
сделай скриншот страницы через chrome-devtools и приложи путь в записи.
Не объясняй код в ответе — только файлы и запись в журнал.
