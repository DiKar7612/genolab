# Фаза 4в — экономика: продажа и секвенирование

Прочитай genolab_tz.md (разделы 3.2 п.4, 5), LOG.md и docs/api.md.
Работай только через экспорты из docs/api.md; нет нужной функции —
остановись и спроси.

Реализуй:
1. js/core/economy.js — монеты и репутация: начисление за заказы,
   списание за секвенирование генотипа и покупку слотов вольера
   (цены из js/data/config.json).
2. Кнопки «Оставить»/«Продать» на карточке существа — рабочие:
   продажа начисляет монеты и освобождает слот.
3. Кнопка «Секвенировать» — списывает монеты, раскрывает генотип
   на карточке; до секвенирования генотип скрыт, виден только фенотип.
4. Покупка дополнительных слотов вольера за монеты.

Ограничения: не менять математику breeder.js, genome.js; обращения
к localStorage — только через save.js.

Проверка себя через chrome-devtools:
1. Пройди E2E: скрестить (используй существующих потомков из вольера) →
   секвенировать → продать → купить слот.
2. Через evaluate сверяй баланс монет после каждого шага с ожидаемым —
   фактические числа запиши в LOG.md.
3. Консоль после каждого шага чистая; ошибки — исправь и повтори.
4. Перезагрузка страницы: баланс и вольер восстановились.

Критерий готовности: полный цикл «скрестил → секвенировал → продал →
купил слот» проходит без ошибок, баланс сходится с ценами config.json.

Соблюдай APPEND_SYSTEM.md, AGENTS.md, RULES.md, SECURITY.md.
После выполнения: запиши запись в LOG.md по формату LOGGING.md
(что сделал / что проверил запуском / что НЕ проверял / файлы вне задания: не трогал),
сделай скриншот страницы через chrome-devtools и приложи путь в записи.
Не объясняй код в ответе — только файлы и запись в журнал.
