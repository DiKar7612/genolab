# Фаза 4а — сводка API (микрокоманда перед фазой 4)

Прочитай файлы js/core/genome.js, js/core/breeder.js, js/core/rng.js,
js/core/economy.js, js/state/store.js, js/state/save.js,
js/render/creature.js, js/render/pennett.js.

Сгенерируй docs/api.md: все экспортируемые функции каждого модуля
с точными сигнатурами (имена, параметры, возвращаемые значения)
и кратким описанием в одну строку. Ничего не выдумывай — только то,
что реально есть в коде; если сигнатура неоднозначна, перечитай файл.

Ограничение: не изменяй код. Создаётся только docs/api.md.

Проверка: перечитай каждый js-файл и сверь: каждый экспорт из файла
есть в docs/api.md, каждая запись api.md соответствует реальному коду.

Критерий готовности: docs/api.md полный и точный. Этот документ далее —
источник интерфейсов для фаз 4б, 4в и 5; изменять его без правки кода
запрещено.

Соблюдай APPEND_SYSTEM.md, AGENTS.md, RULES.md, SECURITY.md.
После выполнения: запиши запись в LOG.md по формату LOGGING.md
(что сделал / что проверил запуском / что НЕ проверял / файлы вне задания: не трогал),
сделай скриншот страницы через chrome-devtools и приложи путь в записи.
Не объясняй код в ответе — только файлы и запись в журнал.
