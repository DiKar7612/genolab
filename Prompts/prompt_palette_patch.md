# Команда для Pi-Cli — правка палитры (фаза 0.5)

Подавать в НОВОЙ сессии.

Блокер фазы 0 решён: паттерн window.GenoLab утверждён — все модули работают
через namespace, ESM-экспорты не использовать.

Фаза 0.5 — переход на арт-стиль «Тёплый клин».

Прочитай ART_STYLE.md в корне репозитория. Это единственный источник правды
по стилю. Тёмная палитра (#1a1a1a, #e8d5b0, #d3d3d3, #d4af37) отменена.

Задание — только CSS и index.html, js-файлы не трогать:
1. css/base.css — заменить переменные палитры на набор из ART_STYLE.md
   (раздел 1), добавить font-size: 110% на html, радиусы и тени по разделу 4.
   Стек шрифтов — системный, без внешних шрифтов.
2. css/layout.css и css/components.css — заменить все жёстко зашитые цвета
   на переменные из base.css (ничего не должно остаться в хексе, кроме
   значений внутри :root). Проверь: нет упоминаний #1a1a1a, #e8d5b0,
   #d3d3d3, #d4af37 в любом файле проекта.
3. index.html — если в разметке есть инлайновые цвета, заменить на классы.
4. Существующие экраны-заглушки должны выглядеть согласованно: светлый фон
   #faf6f0, терракотовая активная кнопка навигации, тёплые карточки.

Проверка через chrome-devtools:
1. Открой file:///D:/LLM_Pi/index.html (путь поправь под фактический репозиторий).
2. Сделай скриншоты всех пяти экранов при 1280px и при 360px.
3. Через evaluate вычисли фактический контраст цвета текста карточки
   к её фону — покажи числа в LOG.md (ожидание: основной текст ≥ 4.5:1).
4. Прочитай консоль — ошибок быть не должно.

Ограничения: файлы вне перечисленных не трогать; если найдёшь цвет,
происхождение которого неясно (генерируется из js) — не меняй js,
а зафиксируй как блокер в LOG.md.

Соблюдай APPEND_SYSTEM.md, AGENTS.md, RULES.md, SECURITY.md. По завершении —
запись в LOG.md по формату LOGGING.md, скриншоты, строка
«файлы вне задания: не трогал». Не объясняй код в ответе — только файлы
и запись в журнал.
