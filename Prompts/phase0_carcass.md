Требования:
1. index.html подключает три CSS-файла и js/main.js (type="module").
2. Пять экранов-заглушек: вольер, скрещивание, карточка существа,
   заказы, кодекс. Переключение через ui/router.js без перезагрузки.
3. base.css — переменные палитры: #1a1a1a (чёрный), #e8d5b0 (бежевый),
   #d3d3d3 (светло-серый), #d4af37 (золото). Системный стек шрифтов.
4. layout.css — сетка экранов, адаптив от 360px (CSS Grid/Flexbox).
5. Все js-модули — рабочие заглушки с экспортами, main.js инициализирует
   роутер.

Ограничения: vanilla JS ES6+, без фреймворков, без CDN, без сборки,
страница должна открываться с file://.

Проверка себя через chrome-devtools:
1. Открой file:///F:/genolab/index.html.
2. Сделай скриншот каждого из пяти экранов.
3. Установи ширину окна 360px и сделай скриншоты — нет горизонтального
   скролла, вёрстка не ломается.
4. Прочитай консоль: ошибок JavaScript быть не должно. Найденные ошибки
   исправь и перепроверь до отчёта.

Критерий готовности: страница открывается локально, навигация
переключает все пять экранов, на 360px всё в порядке, консоль чистая.

Соблюдай APPEND_SYSTEM.md, AGENTS.md, RULES.md, SECURITY.md.
После выполнения: запиши запись в LOG.md по формату LOGGING.md
(что сделал / что проверил запуском / что НЕ проверял / файлы вне задания: не трогал),
сделай скриншот страницы через chrome-devtools и приложи путь в записи.
Не объясняй код в ответе — только файлы и запись в журнал.
