Цель: закрыть версию 1.1 фактическими числами и подготовить отчёт
для визуальной приёмки пользователя. Новой функциональности — НЕТ.

1) Полная регрессия: ВСЕ тестовые страницы (genome, breeder,
   render_grid, config, quests, mutation, species2) по http:// —
   фактические вердикты в LOG_1.1.md; 0 FAIL — гейт.

2) Генетические гейты с новыми числами:

   - мутации: chance=0.03 → ожидаемая частота ±5% (10 000 геномов).

3) E2E полного цикла по file:// И http://: старт → скрещивание

   сейв переживает reload; импорт/экспорт по http://; межвидовой
   guard работает.

4) Старые сейвы: образец сейва MVP (без quests/predictions/muted/
   mutations/codexSeen) — старт без краша, все поля деградируют
   мягко.

   методика как в фазе 6: mobile, 4x throttle). Порог §7: ≥85 / ≥80.

   0 переполнений, 0 целей <44px. Скриншоты всех экранов на трёх
   ширинах + палевый и новый вид крупным планом — пути в LOG.

7) Актуализация ТЗ: §7 — фактические числа v1.1; §9 — сверка каждого

   сделанного; §8 — добавить этапы 7a–7e со статусами и коммитами.

8) LOG_1.1.md — финальная запись фазы 7e: сводка всего, что сделано
