# Фаза 4 — игровой цикл

## Контекст
Прочитай genolab_tz.md (разделы 3.2–3.4).

## Задача
Реализуй полный цикл:

1. Экран скрещивания: два слота родителей (выбор из вольера),
   кнопка «Случайно», анимация скрещивания 1–2 с (CSS-анимация),
   лента результатов с рендером потомков из фазы 2.
2. `js/core/economy.js` — монеты и репутация: начисление за заказы,
   списание за секвенирование генотипа и покупку слотов.
3. `js/data/quests.json` — 5 обучающих квестов и 5 заказов. Каждый квест
   открывает одно понятие в порядке: полное доминирование →
   гетерозигота → рецессивный признак → фиксация признака →
   предсказание расщепления. Тексты — из ТЗ, без нового контента.
4. `js/quests/questEngine.js` — проверка условий квестов (цель вида
   «получи N потомков с фенотипом X» / «выполни заказ»), выдача наград,
   линейная разблокировка.
5. Экран заказов: список активных заказов с фильтром по признакам,
   кнопка «Выполнить» активна, если в вольере есть подходящий потомок.

## Ограничения
- Не менять математику breeder.js и genome.js.
- Анимации только через CSS, без requestAnimationFrame-циклов.

## Критерий готовности
Полный цикл «скрестил → секвенировал → продал → выполнил заказ»
проходится без заглушек и ошибок в консоли; все 5 квестов проходимы
последовательно.
