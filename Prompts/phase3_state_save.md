# Фаза 3 — состояние и сохранение

Прочитай genolab_tz.md (раздел 5) и LOG.md. Реализуй состояние
и сохранение:

1. js/state/store.js — центральное состояние: вольер (массив геномов,
   лимит 12 слотов), монеты, репутация, прогресс квестов. Подписки
   на изменения (простой pub/sub), методы addCreature, removeCreature,
   buySlot.
2. js/state/save.js — автосохранение в localStorage с ключом
   genolab_save_v1 при каждом изменении состояния (debounce 500 мс);
   экспорт текущего состояния в JSON-файл (скачивание) и импорт
   из файла с валидацией структуры (по SECURITY.md: лимит размера,
   никакого выполнения содержимого, только parse + проверка полей).
3. Подключи к карточке существа кнопки «Оставить»/«Продать» (продажа
   по базовой цене из js/data/config.json — заполни его: цены,
   лимиты слотов, шансы мутаций на будущее).

Ограничения: store.js не знает о DOM — только данные и подписки;
все обращения к localStorage — только через save.js. Не менять
genome.js и breeder.js.

Проверка себя через chrome-devtools:
1. Добавь в вольер 2 существа, выполни navigate на тот же file:// —
   вольер и ресурсы восстановились? Зафиксируй фактический результат
   в LOG.md.
2. Через evaluate прочитай localStorage genolab_save_v1 и приведи
   структуру JSON в LOG.md.
3. Через evaluate подмени в localStorage повреждённую строку
   (обрезанный JSON), перезагрузи страницу — приложение показывает
   понятную ошибку, не крашится. Зафиксируй фактическое поведение;
   если крашится — исправь и повтори до успеха.
4. Проверь экспорт (файл скачивается) и импорт (состояние
   восстанавливается).

Критерий готовности: перезагрузка не теряет вольер; экспортированный
файл импортируется и полностью восстанавливает состояние; повреждённый
файл даёт понятную ошибку, а не краш.

Соблюдай APPEND_SYSTEM.md, AGENTS.md, RULES.md, SECURITY.md.
После выполнения: запиши запись в LOG.md по формату LOGGING.md
(что сделал / что проверил запуском / что НЕ проверял / файлы вне задания: не трогал),
сделай скриншот страницы через chrome-devtools и приложи путь в записи.
Не объясняй код в ответе — только файлы и запись в журнал.
