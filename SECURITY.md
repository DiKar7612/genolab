# SECURITY.md — правила безопасности проекта

Проект работает полностью локально (file://), без сервера.
Нарушение любого пункта ниже — блокер, работа останавливается
до явного разрешения пользователя.

## Запрещено агенту

1. **Сеть.** Никаких fetch, XMLHttpRequest, WebSocket, внешних CDN,
   шрифтов, скриптов и картинок из интернета. Все ресурсы — локальные.
2. **Зависимости.** Не добавлять библиотеки, пакеты, npm-модули.
   Нужна зависимость — стоп и вопрос пользователю, не решать молча.
3. **Динамический код.** Запрещены eval(), new Function(), вставка
   строк в setTimeout/setInterval в виде кода.
4. **XSS.** innerHTML разрешён только для разметки, собранной из
   внутренних констант и конфигов проекта. Запрещено собирать HTML
   из содержимого импортированных файлов и пользовательского ввода
   без экранирования (textContent / создание элементов через DOM API).
5. **Хранилище.** localStorage — только ключ genolab_save_v1.
   Не хранить там ничего, кроме игровых данных.
6. **Импорт сейва.** Обязательная валидация структуры JSON по схеме;
   отказ при размере файла свыше 1 МБ; разбор без eval.
7. **Личные данные.** Не собирать, не хранить, не просить. Сейв и
   логи содержат только игровые данные (геномы, монеты, прогресс).
8. **Файловая система.** Изменения только внутри репозитория.
   Не выходить в родительские каталоги, не менять системные файлы.

## Проверка при приёмке каждой фазы

- В сетевой вкладке инструментов разработчика при игре нет запросов
  к внешним адресам.
- В консоли нет ошибок и предупреждений безопасности.
- Импорт произвольно испорченного JSON даёт понятное сообщение
  об ошибке, а не исключение в консоли и не краш.

## Если правило мешает задаче

Стоп. Описать в LOG.md, какое правило и почему мешает, и спросить
пользователя. Молчаливое обходное решение считается нарушением.
