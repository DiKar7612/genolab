# assets/parts/ — модули существа (фаза 2)

Канонические плоские SVG-части, из которых собирается существо
(viewBox 0 0 100 100, канонический окрас — коричневый):

- `body.svg` — лапки + корпус + животик + морда (глаза, рот)
- `ears-sharp.svg` — уши острые (доминантный аллель D)
- `ears-round.svg` — уши круглые (рецессивный аллель d)
- `tail.svg` — хвост (изогнутая линия с круглым краем)
- `pattern-stripes.svg` — узор «полосатый» (3 вертикальные полосы,
  обрезаны по корпусу clipPath; в сборке — поверх корпуса, под мордой)

Фаза 7d — вид Нокт (круглый, большие уши, короткий хвост):

- `noct-body.svg` — круглый корпус
- `noct-ears.svg` — большие уши
- `noct-tail.svg` — короткий хвост (клубочек)
- `noct-glow.svg` — свечение (доминантный аллель E; #e8c76f,
  feGaussianBlur; без аллеля E модуль не применяется)

По file:// браузер не читает внешние SVG-файлы (нет DOM-загрузки SVG,
fetch блокируется CORS), поэтому в `js/render/creature.js` лежит
вшитая копия этой же разметки с подстановкой заливок по фенотипу
(то же решение, что встроенный species.json в genome.js — фаза 0, см. LOG.md).
При правке частей менять нужно оба места.

Порядок наложения в сборке: хвост → уши → корпус → узор → животик/морда.
Размер (крупный/мелкий) — масштаб общей группы: 1.0 / 0.66.
