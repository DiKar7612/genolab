# RULES.md — правила проекта (краткая версия для агента)

## Что это за проект
«ГеноЛаб» — браузерная игра-конструктор по генетике. Vanilla JS,
без фреймворков и сборки. Полное ТЗ — в файле genolab_tz.md.

## Главные правила
1. Фазы делаются строго по порядку: 0 → 1 → 2 → 3 → 4 → 5.
   Тесты фазы 1 — гейт: без «PASS» по всем распределениям дальше не идти.
2. Один промпт = одна фаза. Не смешивать задачи.
3. Правила честной работы — в файле AGENTS.md в корне репозитория.
   Прочитать перед каждой задачей.
4. Изменения — только в файлах, указанных в промпте фазы.
5. Код — vanilla JS ES6+, модули через <script type="module">,
   без внешних CDN и зависимостей.
6. Математика скрещивания (breeder.js) не меняется после фазы 1
   без явного указания человека.
7. Все ответы агента о состоянии кода — проверяемые: либо показываешь,
   как проверил, либо прямо говоришь, что не проверил.
